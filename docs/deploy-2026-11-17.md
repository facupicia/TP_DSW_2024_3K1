Las credenciales se conservaron solo en archivos privados del servidor, sin imprimirse ni subirse a Git. La imagen previa tiene el tag `eventlife-backend:rollback-20261117-1245`.

Para volver al código anterior conservando los datos actuales:

```sh
docker compose -p backend-eventlife \
  -f /home/facu/eventlife-releases/20261117-1245/compose.rollback.json \
  up -d --no-deps backend
```

La configuración de rollback también desactiva `DB_SYNC`. No restaurar automáticamente el dump ni revertir la migración de reparación: se perderían cambios posteriores y se reactivaría estado de seguridad inválido.
