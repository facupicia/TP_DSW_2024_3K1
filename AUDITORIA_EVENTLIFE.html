Top 5 Issues Críticos

1

Ghost Stock in Payment Preferences

Backend Crítico

La transacción del backend valida stock pero no lo reserva atómicamente. Dos usuarios pueden pagar por el último ticket disponible; uno recibe el dinero cobrado pero sin entrega. El stock se reduce solo después del webhook, creando una ventana de race condition.

Race Condition Stock Management MercadoPago
Impacto
Financiero + UX
2

Category Creation Completely Broken

Sinergia Crítico

El frontend envía un string raw como payload, pero el backend espera un objeto { name: string }. La validación Zod falla silenciosamente y la categoría nunca se crea.

Contract Mismatch Zod Validation Feature Broken
Impacto
Feature Inoperable
3

Registration Fields Mismatch

Sinergia Crítico

Los campos pais, provincia, ciudad y address son opcionales en el formulario del frontend pero requeridos en el schema Zod del backend. El registro falla silenciosamente sin feedback al usuario.

Zod Schema UX Failure Form Validation
Impacto
User Acquisition
4

document.write XSS in PDF Export

Frontend Crítico

La función exportPdf() inyecta HTML con datos de usuario directamente mediante document.write(). Un título de evento malicioso puede ejecutar JavaScript arbitrario (Cross-Site Scripting).

XSS document.write User Input
Impacto
Seguridad
5

console.error Exposed in Production

Backend Crítico

Múltiples controladores usan console.error() en lugar del logger estructurado. Esto filtra PII (datos personales) y stack traces a los logs de producción, potencialmente accesibles por terceros.

PII Leak Logging Information Disclosure
Impacto
Privacidad

Resumen de Alta Prioridad

Backend

10
  • N+1 query en getEvents sin joins ni DataLoader
  • QR codes generados secuencialmente dentro de transacción DB
  • Dynamic imports (await import("crypto")) en cada request
  • geolocation.ts es un placeholder sin implementación
  • Rate limiting ausente en endpoints públicos de eventos
  • Configuración de MercadoPago mezcla sandbox y producción
  • Validación de Redis en tiempo de request (no startup)

Frontend

8
  • Race condition en refresh token (múltiples requests simultáneos)
  • SSE sin guardia de carga: UI intenta usar datos antes de ready
  • Math.min(Infinity, ...) como lógica de paginación
  • comprarTicket() bypassea PaymentService directamente
  • Stack traces de error expuestos en builds de producción
  • Hardcodeo de 200 eventos en límite de listado

Base de Datos

13

  • Búsqueda LIKE '%term%' sin índice trigram
  • Columnas VARCHAR sin longitudes definidas
  • Precision inconsistente en decimales (monetarios)
  • Sin enum a nivel DB para campos de estado
  • 8 entidades sin soft delete (@DeleteDateColumn)
